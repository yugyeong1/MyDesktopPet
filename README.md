# 내 비숑 데스크톱 펫

제공된 실제 강아지 사진을 바탕으로 만든 Windows 데스크톱 펫입니다.

## 동작

- 측면: 대기, 걷기, 달리기, 달린 뒤 헥헥
- 정면: 바라보기, 앉기, 기뻐하기, 헥헥
- 자동 상태 전환 및 방향 전환
- 밥 주기, 뛰어놀기, 쓰다듬기, 호감도
- 50%~180% 크기 조절

## 바닥 인식

- 기본적으로 Windows 작업 표시줄 바로 위를 걷거나 달립니다.
- 강아지를 브라우저나 다른 프로그램 창 위로 드래그해 놓으면 내려놓은 높이를 보행선으로 기억하고 그 위를 걷습니다.
- 대상 창을 이동해도 저장된 상대 높이를 따라가며, 최대화된 브라우저에서도 화면 밖으로 올라가지 않습니다.
- 대상 창이 닫히거나 최소화되면 자동으로 작업 표시줄 위로 돌아옵니다.
- 우클릭 메뉴의 `작업 표시줄로 내려가기`로 즉시 복귀할 수 있습니다.

## 실행과 EXE 생성

- 테스트: `run_windows.bat`
- Python 없는 PC용 단일 EXE: `build_windows.bat`
- 완성 EXE: `dist\MyBichonPet.exe`
