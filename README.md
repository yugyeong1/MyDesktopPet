# 내 데스크톱 펫

Windows 바탕화면과 프로그램 창 위에서 걷고, 쉬고, 놀고, 모험하는 데스크톱 펫입니다.

## 주요 기능

- 대기, 걷기, 달리기, 앉기, 기뻐하기, 헥헥거리기 애니메이션
- 밥 주기, 공놀이, 쓰다듬기, 잠자기
- 자동 휴식과 가만히 앉아있기
- 마우스 커서 따라다니기
- 프로그램 창 위 착지 및 작업표시줄 복귀
- 항상 최상단 표시
- 모험, 다툼, 경험치와 레벨
- 일반·레어·초희귀 수집품
- 오늘의 모험 기록
- 이름, 크기, Windows 자동 실행 설정
- 다중 모니터 지원

## 실행 환경

- Windows 10 또는 Windows 11
- Python 3.10 이상
- Pillow
- Tkinter(Python Windows 설치본에 기본 포함)

## 프로젝트 구조

다음 파일과 폴더가 같은 프로젝트 폴더 안에 있어야 합니다.

```text
BichonDesktopPet/
├─ desktop_pet.py
├─ run_windows.bat
├─ build_windows.bat
└─ assets/
   ├─ front/
   │  ├─ 0_0.png ~ 3_3.png
   │  └─ ...
   └─ side/
      ├─ 0_0.png ~ 3_3.png
      └─ ...
```

`assets` 폴더가 없거나 이미지 이름이 바뀌면 프로그램이 실행되지 않습니다.

## Python으로 실행하기

### 간편 실행

1. Python을 설치합니다.
2. Python 설치 화면에서 `Add Python to PATH`를 체크합니다.
3. 프로젝트 폴더에서 `run_windows.bat`를 더블클릭합니다.

`run_windows.bat`는 Pillow가 없으면 자동으로 설치한 뒤 `desktop_pet.py`를 실행합니다.

### 명령 프롬프트에서 실행

프로젝트 폴더에서 다음 명령을 실행합니다.

```bat
py -m pip install Pillow
py desktop_pet.py
```

`py` 명령을 찾을 수 없다는 메시지가 나오면 Python을 다시 설치하면서 `Add Python to PATH`를 체크해야 합니다.

## Windows EXE 만들기

### 자동 빌드

프로젝트 폴더에서 `build_windows.bat`를 더블클릭합니다.

배치 파일이 PyInstaller와 Pillow를 설치하고 다음 위치에 EXE를 생성합니다.

```text
dist\MyBichonPet.exe
```

### 명령 프롬프트에서 직접 빌드

```bat
py -m pip install --upgrade pyinstaller Pillow
py -m PyInstaller --noconfirm --clean --onefile --windowed --name MyBichonPet --add-data "assets;assets" desktop_pet.py
```

생성된 `MyBichonPet.exe`는 Python이 설치되지 않은 Windows PC에서도 실행할 수 있습니다.

## 처음 실행

처음 실행하면 설정 창이 열립니다.

- 강아지 이름 설정
- 크기 설정: 10%~180%
- Windows 시작 시 자동 실행 설정

설정 내용은 자동으로 저장되며 프로그램을 다시 실행해도 유지됩니다.

## 기본 조작

- 강아지 드래그: 원하는 위치나 프로그램 창 위로 이동
- 강아지 더블클릭: 쓰다듬기
- 강아지 우클릭: 기능 메뉴 열기
- 프로그램 종료: 우클릭 메뉴의 `종료`

## 우클릭 메뉴

### ❤️ 현재 상태

상태 정보 창을 엽니다. 창 안의 탭에서 다음 화면을 모두 볼 수 있습니다.

- 현재 상태
- 수집품 / 모험 통계
- 오늘의 모험 기록

### 🍖 밥 주기

- 애정도 +5
- 포만감 +30
- 기분 +6
- 경험치 +2

### 🎾 공놀이

- 화면에 튀는 테니스공이 표시됩니다.
- 에너지 -12
- 기분 +14
- 애정도 +2
- 경험치 +3
- 에너지가 12보다 낮으면 공놀이를 할 수 없습니다.
- `가만히 앉아있기`가 켜져 있으면 자동으로 해제됩니다.

### 💕 쓰다듬기

- 애정도 +1
- 기분 +4
- 자는 중이라면 강아지가 깨어납니다.

강아지를 더블클릭해도 동일하게 쓰다듬을 수 있습니다.

### 💤 잠자기

- 최대 1분 동안 잠을 잡니다.
- 화면에 `Zzz`가 표시됩니다.
- 5초마다 에너지 +3, 기분 +1
- 에너지가 100이 되면 자동으로 깨어납니다.
- 자는 중에 밥 주기, 공놀이, 쓰다듬기 또는 드래그를 하면 깨어납니다.
- 자는 중에 `잠자기`를 다시 누르면 바로 깨어납니다.

### 🪑 가만히 앉아있기

- 체크하면 시간 제한 없이 앉은 상태를 유지합니다.
- 이동, 모험, 다툼, 자동 짖기가 중단됩니다.
- 앉아 있는 동안 에너지가 회복됩니다.
- 앉기 이미지는 `assets/front/1_0.png`와 `1_1.png`만 반복합니다.
- 다시 체크를 해제하면 평소 행동으로 돌아갑니다.
- 마우스 따라다니기와 동시에 사용할 수 없습니다.
- 공놀이나 마우스 따라다니기를 시작하면 자동으로 해제됩니다.
- 선택 상태는 프로그램을 다시 실행해도 유지됩니다.

### 💬 말풍선 표시

- 체크 해제하면 모든 말풍선을 숨깁니다.
- 밥, 공놀이, 쓰다듬기, 착지, 모험, 다툼, 짖기 말풍선이 모두 표시되지 않습니다.
- 말풍선을 꺼도 기능과 기록은 정상적으로 동작합니다.
- 선택 상태는 프로그램을 다시 실행해도 유지됩니다.

### 🖱 마우스 따라다니기

- 커서가 멀리 있으면 달려갑니다.
- 중간 거리에서는 걸어갑니다.
- 커서와 약 65px 이내로 가까워지면 앉아서 기다립니다.
- 커서를 다른 모니터로 옮기면 해당 모니터로 이동합니다.
- `가만히 앉아있기`와 동시에 사용할 수 없습니다.
- 강아지를 직접 드래그하면 마우스 따라다니기가 자동으로 해제됩니다.
- 선택 상태는 프로그램을 다시 실행해도 유지됩니다.

### 🎒 수집품 / 모험 통계

누적 모험, 다툼, 승리 횟수와 수집품을 확인합니다. 정보 창이 수집품 탭으로 바로 열리며 다른 탭으로도 이동할 수 있습니다.

### 📖 오늘의 모험 기록

- 물건을 발견한 모험과 다른 강아지와의 다툼만 기록합니다.
- 밥 주기, 공놀이, 쓰다듬기, 착지는 기록하지 않습니다.
- 기록에는 시간, 종류, 결과가 표시됩니다.
- 하루 최대 200개의 최신 기록을 유지합니다.
- 날짜가 바뀌면 전날 기록이 자동으로 삭제됩니다.
- 수집품과 누적 통계는 날짜가 바뀌어도 삭제되지 않습니다.

### ⬇ 작업 표시줄로 내려가기

강아지를 현재 모니터의 작업표시줄 바로 위로 이동합니다.

### 🔄 펫 초기화

다음 데이터를 처음 상태로 되돌립니다.

- 이름과 크기
- 애정도, 포만감, 에너지, 기분
- 레벨과 경험치
- 수집품
- 누적 모험, 다툼, 승리 통계
- 오늘의 모험 기록

Windows 자동 실행, 말풍선 표시, 마우스 따라다니기, 가만히 앉아있기 설정은 유지됩니다.

> 수집품은 날짜가 바뀌어도 초기화되지 않지만, `펫 초기화`를 직접 실행하면 삭제됩니다.

## 자동 행동과 상태 변화

### 자동 이동과 휴식

- 강아지는 평상시에 대기, 걷기, 달리기, 앉기 등을 무작위로 반복합니다.
- 처음 실행 후 약 30~60초 사이에 한 번 쉬기 시작합니다.
- 이후 약 1~2분 간격으로 자동 휴식합니다.
- 한 번 앉으면 약 15~30초 동안 쉽니다.
- 마우스 따라다니기나 가만히 앉아있기가 켜져 있으면 일반 자동 휴식 규칙보다 해당 기능이 우선합니다.

### 짖기

- 약 45~120초 간격으로 `멍멍!`, `왈왈!`, `멍! 🐾` 중 하나를 말합니다.
- 다른 말풍선이 표시 중이거나 드래그·낙하 중이면 잠시 뒤 다시 시도합니다.
- 자동 짖기는 오늘의 모험 기록에 저장되지 않습니다.
- 가만히 앉아있기가 켜져 있으면 자동으로 짖지 않습니다.

### 상태 수치

- 포만감: 20초마다 1 감소
- 걷기 또는 달리기: 20초마다 에너지 1 감소
- 앉기 또는 정면 대기: 20초마다 에너지 1 회복
- 포만감이 25 미만이거나 에너지가 20 미만이면 기분이 감소
- 포만감이 60보다 높고 에너지가 50보다 높으면 기분이 조금씩 회복
- 각 상태 수치의 범위는 0~100입니다.

## 모험과 다툼

- 모험 이벤트는 약 3~5분 간격으로 시도됩니다.
- 실제 이벤트는 강아지가 걷거나 달리는 중일 때 발생합니다.
- 이벤트 결과는 물건 발견 76%, 다른 강아지와 다툼 24%입니다.
- 모든 모험 이벤트에서 경험치 +5를 얻습니다.
- 다툼에서 승리하면 경험치 +4를 추가로 얻습니다.

다툼 상대는 다음 중 무작위로 선택됩니다.

- 동네 비숑
- 말티즈 친구
- 푸들 친구
- 용감한 시바
- 큰 골든리트리버

승률은 애정도에 따라 약 42%에서 최대 75%까지 올라갑니다.

```text
승률 = 42% + (애정도 × 0.4%p)
최대 승률 = 75%
```

## 수집품

물건 발견이 결정되면 먼저 등급을 추첨하고, 해당 등급 안에서 하나를 동일한 확률로 선택합니다.

| 등급 | 등급 확률 | 종류 수 | 물건 발견 시 각 물건의 확률 |
|---|---:|---:|---:|
| 일반 | 98.8% | 16종 | 6.175% |
| 레어 | 1.1% | 6종 | 약 0.1833% |
| 초희귀 | 0.1% | 3종 | 약 0.0333% |

아직 한 번도 발견하지 못한 물건은 `❔ ???`로 표시되며, 발견하면 아이콘과 이름이 공개됩니다. 등급과 발견 확률은 발견 전에도 확인할 수 있습니다.

## 창 위에 강아지 올리기

- 강아지를 브라우저나 다른 프로그램 창 위로 드래그합니다.
- 발이 창의 윗면 가까이에 있으면 해당 창 위에 바로 고정됩니다.
- 아래에 창이 없으면 중력에 따라 떨어져 작업표시줄 위에 착지합니다.
- 올려 둔 창을 닫거나 최소화하면 작업표시줄 위로 돌아옵니다.
- 수동 드래그는 마우스 따라다니기를 자동으로 해제하므로 옮긴 직후 작업표시줄로 끌려 내려가지 않습니다.

## 항상 최상단 표시

- 강아지와 말풍선에 Windows `HWND_TOPMOST`가 적용됩니다.
- 1초마다 최상단 상태를 다시 확인하고 적용합니다.
- 다른 일반 프로그램을 실행해도 강아지가 뒤로 가려지지 않도록 동작합니다.
- 다른 프로그램의 키보드 포커스는 빼앗지 않습니다.
- 독점 전체 화면 게임과 일부 보안 프로그램 위에는 표시되지 않을 수 있습니다.

## 데이터 저장

설정과 진행 데이터는 다음 파일에 저장됩니다.

```text
%LOCALAPPDATA%\MyBichonDesktopPet\settings.json
```

저장되는 데이터:

- 이름과 크기
- Windows 자동 실행 여부
- 애정도, 포만감, 에너지, 기분
- 레벨과 경험치
- 수집품과 누적 통계
- 오늘의 모험 기록
- 말풍선 표시 여부
- 마우스 따라다니기 여부
- 가만히 앉아있기 여부
- 마지막 가로 위치

수집품과 누적 통계는 프로그램을 종료하거나 날짜가 바뀌어도 유지됩니다.

## 문제 해결

### `Python was not found` 오류

Python 3.10 이상을 설치하고 설치 화면에서 `Add Python to PATH`를 체크합니다.

### `No module named PIL` 오류

```bat
py -m pip install Pillow
```

### 이미지 파일 오류

`desktop_pet.py` 옆에 `assets` 폴더가 있는지 확인하고 `front`, `side` 폴더의 PNG 파일 이름을 변경하지 않습니다.

### EXE 빌드 실패

명령 프롬프트에서 다음 명령을 실행한 뒤 다시 빌드합니다.

```bat
py -m pip install --upgrade pip pyinstaller Pillow
```

### 설정을 완전히 삭제하고 처음부터 시작

프로그램을 종료한 후 다음 파일을 직접 삭제합니다.

```text
%LOCALAPPDATA%\MyBichonDesktopPet\settings.json
```

이 작업은 수집품과 모든 진행 데이터를 복구할 수 없게 삭제하므로 필요한 경우 파일을 먼저 백업합니다.
